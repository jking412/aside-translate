# 旁译 Aside v0.3.0

新增传统划词翻译：鼠标选中网页文字，在选区旁点击“翻译”，即可在小浮窗查看原文与中文译文。

- 默认开启，可在工具栏弹窗或独立设置页关闭。
- 使用当前配置的微软、Google、自备或 AI 服务；单纯选中不会发送请求，点击翻译后才发送所选文字。
- 支持关闭、Esc、点击外部收起、失败重试及长选区分段；20,000 字以上明确提示缩小选区，不静默截断。
- 新选区、切换服务、关闭或停用时，旧的异步结果不会重新打开卡片或覆盖新选区。
- 不改写网页原文，不处理密码、输入框和可编辑区域，也不新增浏览器权限。
- 普通 HTTP(S) iframe 使用既有内容脚本支持划词。

下载 `aside-translate-0.3.0.zip`，覆盖原扩展目录后重新加载，并刷新已打开的网页。更新后直接拖动选中文字即可使用，无需重新配置翻译服务。

本机验证通过 73 项单元测试、55 组浏览器检查（含新增 13 组划词交互），页面脚本错误为 0。

本版继续为预发布，沿用此前 YouTube 在线空字幕响应的验证边界。功能与验证详情见 [README](https://github.com/jking412/aside-translate/blob/v0.3.0/README.md)、[隐私说明](https://github.com/jking412/aside-translate/blob/v0.3.0/PRIVACY.md)及[验证记录](https://github.com/jking412/aside-translate/blob/v0.3.0/docs/verification.md)。
