# 旁译 Aside v0.3.2

修复 YouTube 英文自动字幕重组时丢失部分词间空格的问题。

## 修复内容

- YouTube 会将部分换行作为单独的追加字幕事件。此前这类事件被提前过滤，前后词语合并时可能显示为 `isthat` 等连续文字；现在保留其中的空白分隔，再进行分句与显示。
- 新增真实公开 JSON3 两词样本回归，并验证截图中的 `is that`、`is figuring`、`even improve`、`while massively` 在同类追加换行结构下保持分隔。
- 原生字幕请求、英文显示和发给所选翻译服务的文字使用同一分隔结果。保留词内片段、缩写、小数、中文及已有零宽空格处理。
- 包含 v0.3.1 的 DeepSeek 独立入口、配置草稿兼容和 README 更新。

## 安装与更新

下载 `aside-translate-0.3.2.zip`，解压并替换原扩展目录，在 Chrome / Edge 扩展管理页点击「重新加载」，再刷新已经打开的 YouTube 页面。确认扩展版本为 **0.3.2**；已有翻译服务配置保存在浏览器本机。

## 验证范围

追加换行的丢分隔机制已在真实公开 JSON3 片段上复现，修复前测试失败、修复后通过；另有受控原生字幕桥接检查显示与翻译请求。用户提供的 O_zcc6Xl12g 视频已访问，确认英语 ASR 轨道，但本环境的字幕接口返回空正文，内置文字记录请求也未成功。因此本版没有声称已直接重放该视频 1:21 的原始字幕。详细过程与验证结果见 [验证记录](https://github.com/jking412/aside-translate/blob/v0.3.2/docs/verification.md)。
