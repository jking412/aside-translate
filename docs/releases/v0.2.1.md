# 旁译 Aside v0.2.1

修复英文自动字幕中已有词间分隔没有显示为普通空格，导致 `what you can` 视觉上成为 `whatyou can` 的问题。

- 在字幕片段进入分句、去空白和碎片合并前统一处理零宽分隔 U+200B，覆盖分隔在词中、词尾、独立片段和跨字幕事件的情况。
- 保留原有空格、真实词内碎片、缩写、小数、标点和中文连续文字，不对所有片段盲目插入空格。
- 新增 13 项针对性回归与原生字幕捕获到显示/服务请求的完整受控用例。

沿用 v0.2.0 的网页双语、持久设置页、DeepSeek 默认模型、悬浮入口和安装时权限行为。下载 `aside-translate-0.2.1.zip`，覆盖原扩展目录、重新加载扩展并刷新视频页面即可。

本版继续为预发布。用户提供视频的实际字幕在本次独立浏览器中返回空正文，因此未直接确认该视频原始分隔与在线显示；可复现的分隔处理缺陷已修复。具体证据与边界见 [验证记录](https://github.com/jking412/aside-translate/blob/v0.2.1/docs/verification.md)。
