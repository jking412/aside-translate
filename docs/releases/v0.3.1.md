# 旁译 Aside v0.3.1

这次更新让 DeepSeek 更容易找到，也重新整理了项目首页，方便下载、使用和分享。

## 更新内容

- DeepSeek 成为翻译服务列表中的第二个独立选项，紧跟默认的免费微软翻译。
- 选择 DeepSeek 后直接显示已预填的官方接口和默认模型，无需再次选择服务商。
- 兼容已有的 DeepSeek 密钥、模型与未保存草稿，切换服务后可以继续填写。
- 当前服务摘要正确显示 DeepSeek，并跟随其他窗口的设置更新。
- README 以阅读场景、安装与配置为主，更新 DeepSeek 截图，将详细验证资料放在专门文档。

## 安装与更新

下载 `aside-translate-0.3.1.zip` 并解压，在浏览器扩展管理页加载。已安装用户可以用新包替换原目录，点击“重新加载”，再刷新已有网页。升级不需要重新输入原有的 DeepSeek 配置。

本版保留现有权限范围。翻译文字发送至用户选择的服务，密钥和草稿存于本机。DeepSeek API 费用由用户自己的账户承担。

## 使用说明

YouTube 翻译依赖视频字幕与平台响应，部分环境可能出现空字幕。平台相关的排查方法与验证范围见 [验证记录](https://github.com/jking412/aside-translate/blob/v0.3.1/docs/verification.md)。各服务的实际模型权限和计费以服务商控制台为准。
