# 旁译 Aside v0.1.0

首个公开预发布版本：网页翻译与 YouTube 双语字幕，默认中文。

> **已知限制：真实 YouTube 双语字幕显示尚未验收通过。** 本次视频可以播放、拖动和缩放，但字幕接口正文为0，原生与扩展均未显示字幕。受控字幕演示不代表真实在线成功；此版本适合试用和反馈。

## 下载与安装

下载本页附件 `aside-translate-0.1.0.zip` 并解压，Chrome 打开 `chrome://extensions` 或 Edge 打开 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展”，选中直接含 `manifest.json` 的文件夹。使用扩展无需 Node.js。

另提供 `aside-translate-0.1.0.zip.sha256` 用于校验；自动生成的 Source code 为源码包，使用前需构建。目前没有 Chrome/Edge 商店安装入口。

## 本版功能

- 网页一键翻译/恢复与自动整页翻译开关，动态文字支持，默认自动翻译关闭。
- YouTube 原文与中文两行字幕，媒体时钟同步、播放器缩放、拖动/换片/禁用清理，完整轨与当前字幕DOM回退。
- 网页与字幕共用服务配置：Google公共服务、LibreTranslate、OpenAI兼容、Anthropic Messages、Gemini原生协议；模型ID自填，常用服务商端点预设。
- 原创双行图标、中文最小弹窗、MV3按需权限、零运行时npm依赖。

## 验证与范围

- 34项单元测试与14组隔离浏览器受控检查通过，页面脚本错误0。
- 真实Google公共翻译成功；真实YouTube字幕未通过，见首段。
- 云AI仅官方协议和受控HTTP测试，未使用用户密钥进行计费鉴权调用。
- 原生工具栏、授权对话框、Edge、Chrome120、广告/直播/地区账号差异需补充检查。
- 发布工作流在该版本标签上重新验证、构建、打包、核对SHA-256后上传附件。

翻译文字会发送到所选服务，密钥仅保存在本机且未加密；AI服务可能计费。详情见 [隐私说明](https://github.com/jking412/aside-translate/blob/v0.1.0/PRIVACY.md)、[验证记录](https://github.com/jking412/aside-translate/blob/v0.1.0/docs/verification.md)和[AI服务配置](https://github.com/jking412/aside-translate/blob/v0.1.0/docs/ai-services.md)。
