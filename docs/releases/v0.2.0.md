# 旁译 Aside v0.2.0

本版重新对照用户提供的原版 1.34.4，修正 v0.1.0 在网页双语、字幕取轨、配置和入口上的关键差异。安装 ZIP 后不需要 Node.js 或本机服务。

> 真实 YouTube 在线验收本次仍未通过：新版和原版在同一视频、同机独立浏览器条件下均收到空字幕响应，原生 CC 也为空。本版明确作为预发布，受控验证与在线限制见下文。

## 更新内容

- 网页默认保留原文，整段中文显示在原文后；内联链接与强调参与同段翻译，保留原 DOM 和事件，恢复只移除译文。
- 短行行内、长段分行，视口附近优先加载；滚动和动态文字更新继续处理，代码与输入框保持原样。
- YouTube 捕获播放器实际返回的字幕，自动开启 CC，支持 JSON3 与 XML；提前翻译、媒体时钟、拖动和换片清理，播放器内可关闭或重新开启。
- 英文自动字幕按词级时间整理句子；字幕随播放器缩放，可拖动位置。没有有效自绘字幕时恢复原生字幕显示。
- 新安装默认微软公共翻译，无需密钥；已有用户保存的服务继续保留。网页和字幕使用同一服务，人工中文字幕优先及预先翻译可在设置调整。
- DeepSeek 已填好官方地址、默认 `deepseek-flash`，提供 `deepseek-v4-pro` 建议和自定义输入；只需自己的 API 密钥即可按默认模型配置。
- 新增独立设置标签页；按供应商、按字段即时保存本机草稿，切页找密钥、关闭弹窗、切换服务或同时打开设置页均保留输入。
- 新增页面悬浮球、拖动吸边、快捷面板、位置保存及 Alt+A / Alt+W；跨源与继承来源 iframe 的操作保持同一翻译状态。
- HTTP(S) 网站访问在安装时统一声明，使用核心功能、开启自动翻译和保存接口时不再另外申请权限。浏览器在安装或升级增加权限时仍可能告知一次。

## 安装与更新

1. 下载 `aside-translate-0.2.0.zip` 并解压；根目录应直接包含 `manifest.json`。
2. 在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，加载该文件夹。已有安装可替换原文件夹后点击重新加载。
3. 刷新已有网页。点击网页悬浮入口或工具栏翻译；服务配置可在“在独立页面配置”中填写。

SHA-256 附件用于校验 ZIP。GitHub 自动生成的 Source code 需要构建，使用者应下载上述扩展 ZIP。

## 验证与范围

原包只读行为依据、可复跑的差异场景见 [原版对照](https://github.com/jking412/aside-translate/blob/v0.2.0/docs/parity.md)，实际受控与真实网络结果见 [验证记录](https://github.com/jking412/aside-translate/blob/v0.2.0/docs/verification.md)。本机最终验收为 60 项单元测试、17 组正式扩展浏览器检查和 24 组专项差异检查全部通过；脚本错误为 0。所有正式扩展浏览器回归直接使用交付 manifest，不预先改写权限。

本版仍为预发布。真实网络、账号和地区会影响第三方字幕与翻译接口；未使用用户密钥进行云 AI 计费调用。原版账户、付费服务、OCR、文档处理、术语库和私有站点规则不在本项目范围，原版代码和品牌素材不随包分发。
