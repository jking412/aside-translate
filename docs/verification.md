# 验证记录

本记录依据交付前的实际测试，分别记录受控结果、真实网络结果与未验证范围。日期采用用户的 Asia/Shanghai 时间，浏览器采样时钟和网络结果只代表本机本次运行。

## 证据类型

- Node 单元测试：纯协议、限制、队列和时间轴边界。
- 隔离 Chromium 受控测试：加载真实构建的扩展，拦截的合成网页/字幕与原创媒体，验证 DOM、状态、时钟和清理；不代表真实 YouTube 可用性。
- 真实在线测试：不拦截公共翻译接口和公开视频；网络不可达、缺少轨或无法播放需如实记录。
- 未验证：未实际执行的浏览器、网站、账号地区、直播/广告、商店审核等。

旧工程的 9 份合成输入/35 句逐句等价与播放器对照不属于本扩展测试结论。本项目没有复制其专有分句算法，因此不继承该等价声明。

## 真实在线采样（2026-11-11 23:59，Asia/Shanghai）

在独立配置的 Chromium 143.0.7499.4 中加载当时的真实构建，不拦截网络：

- Google 公共接口经扩展 service worker 实际返回“你好世界。”，验证输入为 `Hello world.`。
- 公共视频 `aircAruvnKk` 页面 HTTP 200，视频可播放，采样中媒体时钟从约 2.71 秒推进至 7.76 秒；随后拖动至 30 秒，继续推进至约 37.01 秒。
- 扩展 overlay 已加载；播放器从 640×360 改至 960×540 时，原文行计算字号从约 14.82 px 变为 22.23 px。
- 字幕端点返回 HTTP 200，但桥接未取得可解析的 JSON3，返回 JSON 解析不完整错误。此轮未记录响应体长度，因此只能确认响应为空或不完整，不能仅凭该错误断言精确的零字节正文。YouTube 原生字幕请求也出现 HTTP 200，12 秒采样窗口内原生字幕和扩展的原译两行均未显示。**本次真实在线字幕验收未通过**，不把页面可达、视频播放或 overlay 存在当成字幕成功。

本轮诊断与截图保存在忽略目录 `output/online/`。后续可运行 `npm run test:online` 复测；脚本记录每个字幕响应的字符数及可解析事件数，不记录签名 URL、Cookie 或账号资料。脚本在真实双语行未出现、播放未推进或拖动未完成时返回非零退出码。不同网络和后续运行可能得到不同结果；最新报告优先于此段历史记录。

此轮真实轨列表还暴露了语言排序问题：首条是阿拉伯语，不能作为视频原始语言。随后对真实元信息的窄诊断确认：默认音轨 ID 为 en-US.4，但 defaultCaptionTrackIndex 指向用户偏好的 zh-CN；该字幕索引不能用于判断语音语言。实现已改为从音轨语言或语言形状的音轨 ID 读取源语言，显式原始音轨标记优先；音轨 ID 不可解析时保守使用英文回退，不猜测字幕偏好。再选择同语言人工轨、其次自动轨，中文目标优先简体人工轨。修复后的字幕相关 Node 测试共 14 项通过，包含上述真实数据形状、未知音轨 ID、显式原始轨与默认配音差异回归。本轮在线采样发生在最终修复之前，不据此宣称修复后的真实字幕通过。窄诊断可运行 node tools/language-inspect.mjs，证据位于 output/online/language-metadata.json。
