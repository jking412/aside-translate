# 界面与图标设计

旁译 Aside 是操作型浏览器工具。沿用既有蓝白界面与原创图标，只扩展完成网页翻译、YouTube 双语字幕所需的入口与设置；没有账户、同步、OCR、本地模型或文档处理入口。

## 视觉约定

- 主色 `#165DCC` 用于翻译动作、已启用开关和图标底色；正文 `#203047`、次要文字 `#627187`、分隔线 `#E2E8F0`、白底 `#FFFFFF`。
- 图标辅色 `#8EE5DA` 表示译文行；界面沿用系统中文 UI 字体，无远程字体。
- 工具栏弹窗为 344 px 单列、22 px 外边距；主按钮 46 px。优先显示翻译/恢复与两个总开关，服务编辑默认折叠。
- 独立设置页使用同一字号、颜色和字段组件，最大内容宽度 680 px；窄窗口保持单列，可正常滚动，没有横向溢出。
- 所有控件有键盘焦点样式，开关使用原生复选框和 switch 角色，状态使用 live region；不添加自动播放动效。

## 原创图标

`assets/icon.svg` 是唯一设计源文件，没有使用旧扩展的图片、品牌或字形素材。蓝底承载两条错落对话行：白色原文在左上，薄荷色译文在右下，表示译文陪伴原文，呼应 Aside。

`npm run icons` 使用开发依赖 `@resvg/resvg-js` 确定性生成 16、32、48、128 px PNG。16 px 在 1 倍像素、浅色和深色工具栏背景下检查，上下两行和蓝色间隔可辨；尺寸预览不替代真实浏览器工具栏安装验收。

## 弹窗、持久设置页与草稿

工具栏弹窗保留一键翻译/恢复，翻译进行中仍能恢复。服务配置区提供“在独立页面配置”，打开普通扩展设置标签页：切到服务商页面获取密钥不会关闭它。浏览器在安装时统一告知网站访问权限，功能开关和服务保存不再重复调用运行时网站授权。

未保存的服务、供应商、端点、模型和密钥立即写入本机草稿；不等待失焦、延迟回调或弹窗关闭。草稿按供应商及字段分别存储，切换供应商保留各自输入；popup 和设置页同时编辑不同字段时，不会用旧的整份快照覆盖另一窗口的新值。其他窗口的更新同步到未编辑字段，失焦后读取最新字段；保存前重新读取草稿，再激活所选配置。

草稿与已启用翻译配置分离，编辑不会触发翻译请求。密钥使用密码输入，只保存在 `chrome.storage.local`，不做云同步。已保存设置也只更新当前操作涉及的字段，避免一个窗口更改开关时回写另一窗口的旧服务配置。URL、模型与密钥格式错误显示固定、可操作的校验说明，不输出未知错误内容或密钥。

## 服务与字幕设置

新安装默认微软公共翻译，同时保留 Google 公共服务和自备 LibreTranslate / OpenAI 兼容 / Anthropic / Gemini。已明确保存的用户服务选择继续保留。

DeepSeek 预设自动填入 `deepseek-flash`，模型输入提供 `deepseek-v4-pro` 建议并允许自定义；用户不需要从空白开始输入模型。名称与端点已于 2026-11-12 核对 [DeepSeek 官方文档](https://api-docs.deepseek.com/en/)，不据此宣称所有账户与云端鉴权已在线通过。

独立设置页还提供默认开启的“优先使用人工中文字幕”和“预先翻译视频字幕”。没有可用人工轨时仍调用所选服务；关闭人工轨优先后按服务翻译。popup 只保留字幕总开关，避免把日常操作做成复杂设置中心。

## 网页悬浮入口

`src/content/floating.js` 独立实现原包可观察的主要交互，沿用旁译原创视觉：主按钮一键翻译/恢复，旁边按钮展开快捷面板，面板提供状态和独立设置入口。API 配置与密钥不放进网页中的浮窗。

拖动超过 6 px 才视为移动，松开后吸附到左右近侧并保存位置；拖动不会误触翻译。窗口缩放时将入口限制在可视范围内，面板根据剩余空间向上或向下展开；Esc、外部点击或关闭按钮收起。通过设置关闭悬浮入口时，节点、监听和轮询一起清理。

原包 `extension/content_main.js` 的拖动/浮球行为只作为交互证据，没有复制其实现、图标、样式、品牌或其他功能。更多功能边界与原包证据见 `docs/parity.md`。

## 本次验证与证据边界

在独立 Chromium 143.0.7499.4 中运行 `node tools/ui-parity-test.mjs`。先记录默认模型为空、popup 关闭后丢稿、切供应商串稿、设置页缺失、运行时授权调用及无悬浮入口的失败，再修复；之后还先复现了跨窗口旧快照覆盖问题，再改为逐字段存储。

当前 9 组受控 UI 检查通过：DeepSeek 默认、快速关闭后恢复草稿、供应商独立草稿、跨窗口字段隔离、设置页切标签和重载、无重复网站授权、HTTPS 具体错误、悬浮翻译/恢复/展开/收起/拖动，以及原有自定义配置不改动保存。

检查使用本项目真实源 UI 与 Chrome API 受控替身，不代表原生安装授权、真实翻译服务或 YouTube 在线字幕通过。截图和结果在 Git 忽略的 `output/ui-parity/`：`popup-default.png`、`options-default.png`、`options-deepseek.png`、`settings-narrow.png`、`floating.png`、`result.json`。公开界面截图没有填入密钥；其他回归数据仅用合成值。正式构建与真实网络验证由对应端到端记录另行说明。

视觉检查采用两轮：先检查桌面设置页，再确认 344 px 弹窗、窄设置页和浮窗。最后运行一次 Impeccable detector，返回空发现列表；本机缺少 HTML 解析依赖，工具降级为正则检查，未执行 computed contrast，不能把它视为完整可访问性验收。未更新技能或为检测追加依赖。
