# 界面与图标设计

旁译 Aside 是操作型浏览器工具。弹窗首先提供当前页的一键翻译 / 恢复，其次是自动网页翻译与 YouTube 双语字幕两个开关；服务配置收进折叠区域，提供 Google 公共服务、LibreTranslate 及三种 AI API 协议；AI 模型 ID 由用户填写，服务商预设只填接口地址，不内置过时模型列表。界面只有中文目标语言，不提供账户、同步或其他功能入口。

## 视觉约定

- 主色 `#165DCC`：翻译动作、已启用开关与图标底色。
- 正文 `#203047`、次要文字 `#627187`、分隔线 `#E2E8F0`、白底 `#FFFFFF`。
- 图标辅色 `#8EE5DA`：下方译文行。辅色仅用于图标，保持弹窗视觉安静。
- 字体优先系统中文 UI 字体；19 px 名称、15 px 主按钮、13 px 操作行、11–12 px 状态与说明。没有远程字体。
- 344 px 单列弹窗，22 px 外边距。主按钮 46 px，开关按行呈现，配置默认折叠。所有输入与状态在同一阅读顺序中。

设计审查时删去了独立功能卡片和装饰性标语，避免把两个开关做成复杂设置中心。唯一鲜明的视觉元素是原创「原译并行」图标。

## 原创图标

`assets/icon.svg` 是唯一设计源文件，独立绘制，没有使用旧扩展的图片、品牌或字形素材。蓝色底形承载两条相向的对话行：左上的白色表示原文，右下方错落的薄荷色表示中文译文；译文陪伴原文，呼应 Aside。两种长度也对应字幕中原文与译文的自然差异。图标不使用微小文字，在 16 px 下保留两条可辨认色块与间隔。

运行 `node tools/icons.mjs` 从 SVG 生成 manifest 与 action 所需的 16、32、48、128 px PNG。栅格化仅使用开发依赖 `@resvg/resvg-js`，PNG 不包含外部资源。修改图形时只改 SVG，再重新生成所有尺寸。

## 交互与可访问性

主按钮随当前页面状态显示“翻译此页”或“恢复原文”，翻译进行中仍可恢复。自动翻译首次开启时，由当前用户操作触发可选网页权限申请；取消授权会回滚开关。自备服务保存时只申请对应站点权限。错误消息说明可采取的下一步，不输出密钥。

开关为带可访问名称的原生复选框，提供 switch 角色；所有控件有键盘焦点样式，状态使用 live region，保留强制颜色模式下的原生开关。服务配置中的密钥使用密码输入框，仅保存到扩展本机存储。
## 本次视觉核验

在独立 Chromium 143.0.7499.4、1 倍设备像素比下，检查默认弹窗、恢复原文状态、LibreTranslate 与 AI 配置展开状态；344 px 弹窗无横向溢出。截图与结果位于被 Git 忽略的 `output/playwright/ui-review/`。配置检查使用 Chrome API 受控替身，验证开关权限拒绝后回滚、服务商预设填充、模型 ID 与服务保存；这不代表真实扩展权限对话框或线上服务验证。

16 px PNG 按实际像素大小分别放在白色与深色工具栏背景上，并以最近邻放大复核：上方白色行、下方右移的薄荷行和中间蓝色间隔均保留。32、48、128 px 也已检查。该预览验证图标的小尺寸栅格辨识度，实际浏览器工具栏安装效果由扩展端到端验证另行确认。
